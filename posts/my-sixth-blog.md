Accessibility is not only about following technical rules. It is also about making a website usable for people with different needs, devices, and contexts. At this stage of the VintaArchive prototype, I evaluated the website through WCAG accessibility principles, usability testing, and technical reflection. My goal was to understand whether users could navigate the site clearly and complete key actions such as browsing exhibitions, viewing item details, logging in, saving items, and managing their profile.

The main accessibility framework I used was WCAG, especially the four POUR principles: Perceivable, Operable, Understandable, and Robust. For VintaArchive, “Perceivable” means that important content such as item images, prices, tags, descriptions, and exhibition information should be clear and readable. Since the interface uses a brown vintage colour palette, contrast is especially important. Images also need meaningful alt text and fallback states so users can still understand the content if an image fails to load or if they use a screen reader.

“Operable” was particularly relevant to the exhibition page. Users enter exhibitions through door-like elements, and the hover effect makes the interaction more engaging. However, hover alone is not accessible for touchscreen or keyboard users. Therefore, this interaction should also support clicking, tapping, and keyboard navigation. “Understandable” relates to clear labels, buttons, navigation states, and feedback messages, especially because the site includes exhibitions, marketplace listings, item detail pages, forms, and profile pages. “Robust” reminded me to use semantic HTML, consistent templates, and clearer form structures so the website can work reliably across browsers and assistive technologies.

My testing goal was to identify practical issues that could affect real users, rather than only checking whether the website looked visually complete. I reviewed layout, spacing, text hierarchy, and labels, then manually clicked through the main pages to test navigation. I also checked accessibility issues such as image loading, alt text, heading structure, colour contrast, and button clarity. Finally, I tested functional edge cases, especially registration, login, logout, likes, and saved items.

One important technical area was the cookie-based login system. Since VintaArchive includes personalised features such as liked items, saved items, uploaded items, and profile content, the website needs to identify the current user. When a user registers, their email is saved in the database. If another user tries to register with the same email, the system rejects it, which helps prevent duplicate accounts and maintain data integrity. Cookies keep the user logged in across pages, while likes and saved items are stored in the database. This means that after logging out and logging back in, users can still access their previous activity.

The testing results showed that the overall concept and visual direction were clear, but several areas still need improvement. Some images need better alt text and fallback states. The navigation bar needs clearer hover and active states so users know where they are. Item cards could also be improved with more consistent spacing and clearer labels for price, trade type, and tags. From a usability perspective, users may understand the vintage theme quickly, but actions such as “barter” or “save” should be explained more explicitly.

For future development, I would improve the site in four main ways. First, I would strengthen accessibility by improving alt text, contrast, and keyboard navigation. Second, I would refine the login system with clearer error messages and safer session handling. Third, I would use analytics to understand which exhibitions users enter, which categories they view, and where they leave the site. Finally, I would improve the responsive layout for mobile users. Overall, this process showed me that accessibility and usability are not final checklist tasks. They should be considered throughout design and development to make the product more inclusive, reliable, and professional.
